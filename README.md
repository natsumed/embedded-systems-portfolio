# Embedded systems portfolio

I am Mohamed Fathallah, an embedded systems engineer. These short summaries describe my contributions to team projects. Source code and internal project material are kept private.

## WiFeeder

I contributed to an RFID-based feeding system built around STM32, ESP32, and a Raspberry Pi. My work included device communication over UART, ESP-IDF/FreeRTOS tasks, motor and encoder integration, C++ services on Linux, MQTT integration, and testing.

## Camera control application

I worked on a C++/Qt application for Linux that displays RTSP video and accepts joystick or keyboard input for camera pan, tilt, and zoom control. My contribution focused on application behavior and hardware integration.

## UAV ground control

I contributed C++ and Qt/QML work to mission-planning and ground-control features involving MAVLink and PX4. I supported integration and validation through simulation, bench tests, and flight tests.

## Wireless backhaul deployment

I supported field coordination, router commissioning, system integration, and throughput validation for a wireless backhaul project.
